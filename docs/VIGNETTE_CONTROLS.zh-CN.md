# 暗角半径与柔边：有界 SDR 控制

本轮在已有暗角上增加半径和柔边，均为 0.25–2.00 的无量纲数值，默认 1.00。强度仍为 0–1。先选择图片片段与暗角，在特效面板调整后点击“应用特效设置”；不是实时拖拽渲染。模糊不显示这两个选项。

## 数学、默认兼容和位深

令 W/H 为完成调色和画布适配后的项目尺寸，x/y 为整数像素坐标：

- dx = trunc(x − W/2)，dy = trunc(y − H/2)，偏移向零截断。
- u = sqrt(dx² + dy²) / sqrt((W/2)² + (H/2)²)。即半对角线归一化距离，不是水平或垂直半径。
- 非默认参数：q = min(1, (u / radius)^(1 / feather))。
- gain = cos(amount × π/2 × q)⁴。
- 每通道 output = floor(input × gain)，读取使用 nearest，避免最末行列被双线性取样改变。

较大的 radius 保护更宽的中心；较大的 feather 让暗化延伸向内，较小值让中心更平坦、变化更靠外。这里的“柔边”是明确定义的指数形状，不是像素羽化距离，不声称复刻 Adobe 或 Resolve 的数学。clamp 限制有效距离，避免小半径导致 cos 周期性重新变亮。强度 0 或关闭精确旁路，参数仍严格验证。

半径和柔边同时为 1.00 时，保留原有分支、滤镜表达式与行为：预览/H.264 为旧版 8 位 vignette，高位深为已有 RGB16 径向乘法。迁移旧工程不能改变其画面。只要任一形状参数非默认，预览/H.264 使用 gbrp 8 位 RGB 显式表达式；ProRes 使用 gbrp16le 原生 RGB16 表达式。只要 8 位片段特效链中存在有效非默认形状，整条特效链固定使用 RGB，混用旧暗角时显式切换 RGB24/GBRP，不让 FFmpeg 自动插入 YUV 转换；几何变换后再显式转换为 Rec.709 限幅 YUV。因此即使从默认值只移动很小一步，H.264 的颜色变化也可能包含处理路径转换的差异，不只是半径／柔边变化。两者均处理编码 Rec.709 RGB 码值，不是线性光或 HDR，8 位与 16 位结果不保证逐像素相等。

## 阶段、操作和迁移

调色/LUT → 项目画布适配 → 按列表顺序的片段特效 → 片段变换 → 视频合成 → 贴纸/字幕。半径相对项目画布，不是原素材尺寸；移动/缩放片段会连同暗角移动/缩放。当前帧调色检查在特效前，不显示本轮暗角改变；应重建完整预览或检查导出。

工程 schema28 保存半径/柔边；旧版本迁移默认 1.00，不接受伪装旧 schema 的新参数。撤销/重做、恢复、复制片段和项目往返保留参数。特效更改不重复生成未变的调色源缓存，但最终效果需重新渲染。半径/柔边未开放关键帧、中心移动、椭圆比例、跟踪或高光保护。

## 性能和验收边界

非默认表达式由 CPU 逐像素解释，明显慢于原版 8 位暗角；高位深也非 GPU 实时效果。本机 Linux 单帧 RGB16 三次样本的中位耗时：640×360 约 0.26 秒，1920×1080 约 1.71 秒（包含 FFmpeg 启动；半径 0.75、柔边 1.5、强度 0.65）。同期默认 RGB16 暗角约 0.22／1.30 秒；这不是跨平台速度保证，也不是视频连续播放帧率。继续使用现有取消、超时和临时文件清理。导出前重新验证 RGB16 实际像素能力，不缓存“支持”结论，也不允许静默 8 位回退。字幕、静态 PNG 与高斯模糊支持范围不变，动画贴纸高位深支持未扩大。

验证使用合成素材、独立径向 oracle、RGB16 低位负对照、实际 H.264/预览/ProRes 解码、奇偶窄画布内部数学、默认历史渲染一致性及模型/UI 状态流。最终统计见同轮终结证据。Linux/offscreen 不代表 Windows/macOS 原生安装、签名、公证或 main 已发布；本轮不新增依赖、不上传用户素材。

## 同轮回归发现的试听重试修复

广泛 UI 回归额外发现本地语音试听的既有竞态：任务启动后才连接结束回调，极快失败可能留下已删除任务引用、影响重试。现将试听状态与结束回调在启动前注册；确定性测试强制成功、失败、取消都在启动函数返回前结束并处理信号，验证清理与控件恢复。此修复不改变配音内容、模型、网络或付款范围。
