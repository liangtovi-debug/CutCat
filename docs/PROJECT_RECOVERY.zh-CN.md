# 剪辑猫：本地自动恢复

## 怎么用

- 编辑期间每 30 秒检查一次。有未保存的内容变化时，写入本机恢复快照；不替代“保存项目”。第一次快照前、以及最近一次快照后的编辑仍可能在崩溃时丢失。
- 异常退出后重新启动，右下角会显示可恢复数量。也可从“文件 → 恢复未保存的项目”打开管理窗口。不会弹出强制恢复提示或自动覆盖原项目。
- 选择快照，点击“恢复副本”。当前项目若有未保存改动，仍会询问保存/丢弃/取消。恢复后是独立未保存副本，撤销历史不跨项目；点击保存时必须自行选择目标文件。
- 关闭恢复管理窗口不会丢弃快照。点击“丢弃快照”并确认，仅删除该编辑会话的恢复快照，不删除原项目或素材。
- 另存成功、确认放弃当前项目并实际切换或正常关闭时，清理该会话的恢复快照。取消另存、取消文件选择、打开失败或取消新项目格式选择，均保留当前内容和恢复快照。若快照清理失败，会显示非模态错误提示，残留快照可能仍会出现在管理窗口。
- 撤销到已保存状态后不再生成快照；恢复副本在正式保存前仍视为未保存。重复触发但内容未变时不会反复写盘。

## 保存了什么

保存完整项目模型，包括素材引用、片段/精确时间映射、调色/特效/变换、字幕、贴纸、音频及来源信息。仅存文件引用，不复制视频、音频、图片、字体或音效，不上传任何素材，不保存 API 密钥或账户设置。源素材若移动，仍需“重新链接缺失素材”。

恢复文件位于系统应用本地数据目录内的 project-recovery-v1 子目录，不放入原项目目录。每个编辑会话独立标识；同一个原文件的不同编辑会话不会互相覆盖。正在运行的会话不会列在待恢复列表中。

## 安全边界

快照采用临时文件、落盘刷新和原子替换；读取时验证结构和大小。若最新快照损坏，可使用仍有效的较早代；中断的临时文件不会当成项目恢复；只有临时残片或全部损坏的会话可明确选择丢弃，不会被伪装成可恢复项目。每个会话保留最近 3 代，最多 32 个未处理会话；达到上限时提示处理已有恢复，不暗中淘汰未处理的项目。

恢复副本默认不沿用原项目保存目标，但用户在保存对话框中仍可明确选择原文件；想保留两份，请选择新文件名。快照不是长期备份，也不能恢复素材本身。进程/文件系统锁与原子替换用于本机正常文件系统；不建议将恢复目录改到网络盘或同步盘。

## 验证范围

仅记录实际完成的 Linux 源码、无显示器 Qt 和合成媒体验证。不是 Windows/macOS 原生安装包验收，不表示已经推送私有仓库。原有画面变换、渲染性能及透明度限制不因增加恢复而改变。
