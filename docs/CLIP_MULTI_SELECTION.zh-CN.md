# 片段多选、整体移动与非波纹删除

本轮是有边界的本地源码/offscreen 验证，工程仍为 schema30。Windows/macOS 安装包未重新构建或验证；历史安装包结果不覆盖本轮源码。

## 操作

- Shift 点击片段可逐个加入/取消选择，支持四条现有视频/音乐轨；最后一个取消后为空选区。
- 点击未选片段改为单选。按住已选片段中部拖动，整个选区以同一个整帧差水平移动，保留各自轨道、间距、源区间和属性。
- 点击已选片段但未形成拖动，松开时收为该片段单选。普通单选拖动保留同类轨道之间移动的原有功能。
- 普通点击片段边缘收为单选并使用已有边缘修剪；Shift 点击边缘仅切换选择，不修剪。
- 多选时 Delete 是一次非波纹删除，留下空隙，不移动其他对象；一次撤销恢复全部。媒体资源不删除。
- 字幕、贴纸、特效不是片段多选成员。切换到这些对象会清空片段选区。
- 切到字幕或贴纸时，特效面板可保留独立的只读列表及未提交参数，但不能应用、移动或删除其特效；明确重新点击特效行才激活该目标。多选期间不使用这份历史上下文作为隐式目标，新工程会使旧上下文失效。
- 多选检查器明确提示仅支持移动和删除，分割、波纹删除、调色、速度、淡入淡出、单片段 AI/当前帧工具不可隐式作用于主片段。

## 安全语义

选择本身不修改工程、不增加撤销记录、不让预览过期。拖动只生成草稿；松开才验证整组选区最终位置并提交一次。任何一个片段越过时间零点或造成最终同轨冲突，整组不提交。被选片段旧位置不作为暂时碰撞障碍。无自动寻找空位、逐片段夹紧或逐片段吸附。

吸附以被拖动片段为锚，排除选区自己的边缘；同一个吸附差应用到所有选中片段。无效位置以红色虚线和原因提示保留。Esc、失焦、隐藏、窗口停用、缩放、选择变化、工程/编辑版本变化都取消草稿。旧弹窗和异步结果受到完整选区及选择代次约束，不能在切换后误写。

文本、数字、下拉框、输入法组合、对话框和媒体列表焦点不允许 Delete/Split 快捷键误删时间线。特效列表在专业模式下仍可删除明确选中的特效。

## 与付费剪辑软件的本轮对比

Adobe Premiere 的官方文档支持 Shift 点击离散片段并对选区移动或删除；多选后 Delete 保留间隙，Ripple Delete 是独立动作。本轮补齐这一基础操作范围，而非它的完整选区/链接体系。

- [Premiere：选择片段](https://helpx.adobe.com/uk/premiere/desktop/edit-projects/change-clip-sequence/select-clips.html)
- [Premiere：删除片段及波纹删除](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/remove-clips-from-a-sequence.html)

Final Cut Pro 的离散多选使用 Command 点击，不是 Shift 点击；其默认 Delete 会波纹删除，Shift-Delete/替换为空隙才是保留间隙的路径。不能将本轮行为说成 FCP 默认 Delete 的等价实现。

- [Final Cut Pro：选择多个片段](https://support.apple.com/en-ca/guide/final-cut-pro/ver28912fd/mac)
- [Final Cut Pro：删除及替换为空隙](https://support.apple.com/en-lamr/guide/final-cut-pro/verc5d34129/mac)

同帧差、固定轨道、碰撞全有或全无、单次撤销是本轮 CutCat 的验收约束，不泛称所有竞品的内部实现。未实现框选、全选、组/链接、成组波纹、批量调色/速度/淡入淡出、磁性时间线、轨道锁或任意轨道数量。Resolve/剪映专业版的具体修饰键与原子提交语义本轮未充分核实，不作对齐声明。

## 验证与限制

覆盖原子模型、跨四轨/不连续/同媒体实例、分数源尾、预览与撤销、Shift/窄片段边缘、焦点保护、陈旧手势/弹窗/异步返回；合成编号视频与 PCM 脉冲验证移动和删除后的时间位置，保存重开及波形源身份/映射不变。保留既有边缘修剪与波形回归。精确收集全套测试、分片 JUnit 和源码起止身份另附本地回执。

这些结果不等于原生桌面鼠标/屏幕缩放/系统输入法体验已验证，也不等于安装包、GPU 实时预览、真实用户素材或付费软件全部功能已经达标。
