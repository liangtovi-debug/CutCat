# 画面动画合成性能：保持精度，减少重复求值

本轮只优化已有画面动画的合成热点，不增加控件、工程字段或依赖。schema32、保持／线性插值、隐藏关键帧、局部项目帧 N、静态旋转／镜像、透明几何边界和 straight alpha 的语义保持不变。不是 GPU、代理媒体、实时查看器或成熟付费编辑器体验对等。

## 先定位，再优化

相同 1080p 三帧合成夹具的阶段测量：原始 RGB16 复制约 0.15 秒，添加 alpha／保护边约 0.17 秒，包含逆变换与 alpha 的 geq 几何前缀约 21.25 秒，完整前景约 21.62 秒，下层全色度扩展约 0.11 秒，完整合成约 21.87 秒。不同阶段分别运行，不能将差值当作精密的逐滤镜 CPU 归因；足以定位主要成本在 geq，而非原始 I/O 或颜色格式准备。

首次阶段测量与另一次基线计时重叠，已保留原始回执并明确标注；正式前后重复对照在单一控制器内串行执行，记录主机负载和 FFmpeg 自身 CPU／墙钟时间。主机不是独占机器。

原实现每个像素、每个颜色／alpha 平面都重新计算四项只依赖 N 的关键帧表达式。本轮为每个 geq 平面／线程切片保留当前帧的四个结果，仅首次遇到该帧时计算，像素坐标和插值数学完全沿用原表达式及运算次序。寄存器 9 保存 N+1，使从 0 开始的首帧不可能误用零初始化的缓存；每个切片独立初始化，不依赖 X=0、Y=0，也不跨滤镜实例共享状态。

没有提前计算倒数、重排仿射系数、减少 RGB16／10 位精度、缩小画面、改变色度或色彩范围。缓存算法标识升级，防止误用旧的最终动画预览缓存；几何之前的调色缓存和无动画路径不变。每次动画渲染仍进行多帧行为能力探测，失败明确拒绝，不输出静态首帧或低位深回退。

FFmpeg 官方依据：[geq 的 N 及每切片表达式状态](https://ffmpeg.org/ffmpeg-filters.html#geq)、[表达式寄存器 st/ld 与条件求值](https://ffmpeg.org/ffmpeg-utils.html#Expression-Evaluation)。本机字节验证是对已安装 FFmpeg 的实证，不代替所有版本的证明。

## 可复现计时

使用 scripts/benchmark_clip_motion_cache.py，在源目录运行 Python 并提供一个尚不存在的 --output 目录。它只使用合成媒体，顺序执行旧函数夹具及新函数；每种尺寸／位深重复两次，第二次颠倒 AB 次序，保存输入／图／输出哈希和完整 FFmpeg 日志。当前基准脚本使用 POSIX 主机负载接口；不是 Windows 原生基准工具。

三帧、两个线性关键帧，x 从 -40 到 40、scale 从 0.4 到 0.6、不透明度从 0.25 到 0.75，静态旋转 17 度。1920×1080 与 3840×2160，8 位 4:2:0 与 10 位 4:2:2 交付格式；中间仍为 full-chroma straight-alpha。单滤镜线程、原始 RGB16 前景和原始 YUV 下层。

计时包括进程启动、输入字节重复分配、原始管道／文件读取、滤镜、rawvideo 编码和 stdout 捕获；不含夹具建立／写文件、图构造、素材解码、调色、能力探测、音频、交付编码或 UI。另测五次 ffmpeg -version 启动耗时，它不是完整滤镜启动成本，不能简单扣除后宣称稳态 FPS。每帧值只是三帧总耗时的摊销，不是实测播放器吞吐。只有两个重复，不报告统计显著性或任意工程速度承诺。

本机正式串行对照（每项两次，中位数；每次 3 帧）：

- 1920×1080／8 位：21.67 → 9.40 秒，2.31 倍，减少 56.6%；两次输出哈希均与原基线一致。
- 1920×1080／10 位：21.69 → 9.64 秒，2.25 倍，减少 55.6%；两次输出哈希均与原基线一致。
- 3840×2160／8 位：86.25 → 36.96 秒，2.33 倍，减少 57.1%；两次输出哈希均与原基线一致。
- 3840×2160／10 位：85.43 → 37.99 秒，2.25 倍，减少 55.5%；两次输出哈希均与原基线一致。

1080p 约 3.1–3.2 秒／帧，4K 约 12–13 秒／帧（包含上述开销的摊销值），因此仍明显不是实时播放。完整 16 次记录见 [原始计时与哈希](CLIP_MOTION_PERFORMANCE_RAW.json)。FFmpeg -version 的五次启动约 0.060–0.073 秒，不能等同完整滤镜初始化。

## 像素与回归验收

独立旧函数来自已验收原始文件，函数正文和来源 SHA256 固定保存。120 项有效动态组合逐字节比较颜色转换前的 GBRAP16 以及最终 YUV；覆盖两种位深、透明／不透明外部、1／4 个滤镜线程、首帧非默认值、首个正时间键、负时间／隐藏键、保持边界、128 个键及极值时间、最小／短切片／合法奇数高画布、非均匀逐帧 RGB16 和覆盖完整码值范围的随机下层。另有 24 项无动画／空关键帧完整滤镜串一致性，以及 1 项固定参考函数正文 SHA256 检查，共新增 145 项。

这比仅比较最终输出的容差更严格，防止 YUV 量化掩盖 RGB16 或 alpha 的误差。生产数学没有改变，但有限合成样本不构成对所有浮点输入的形式证明。完整原有全量回归、逐节点回执、开始／结束源码哈希、新归档解压复测以本轮最终报告为准。没有 UI 改动，无须重复制作界面截图；既有 UI 回归仍在全量中。
