# 时间线源音频波形（本地验证轮）

音频可用的现有片段行显示第一条音频流的源波形，覆盖带声音的视频以及音乐／音效片段。顶部保留名称，下方显示振幅包络；静音时波形变暗。页脚及提示明确标注「源音频波形 · 增益／淡化前」。

这是帮助定位素材的显示功能，不是混音器、响度计或削波检测器，也不表示变速算法处理后瞬态的精确位置。增益、淡入淡出、静音不改写缓存峰值。工程仍为 schema 30；选区、点击／拖动区域、编辑历史、渲染和导出没有改变。

## 处理与边界

- 只读取本地媒体，以 FFmpeg 第一条音频流解码到 48 kHz 浮点 PCM；每个采样取各声道绝对值最大值，反相信号不会因混为单声道而抵消。
- 流式分块生成多分辨率包络。初始桶宽为 128 个采样（约 2.67 ms），长素材自动按二倍粗化；4 小时上限附近最多约 85.3 ms。放大只重新聚合已有包络，不提高已经丢失的分辨率。
- 复用现有有理数时间映射与音频采样边界，支持截取、滑移、拆分、移动、撤销、1/4–4 倍速、音频偏移和不足部分补静音。它是近似源时间包络，不承诺处理后逐采样瞬态对齐。
- 为避免显示选区外的峰值，跨越截取边界的部分桶会被省略。这可能漏掉极短的边缘瞬态；已知文件结尾及片段末尾补帧不会复制声音。
- 单个工作线程在界面外检查文件身份及解码，只有一个解码子进程活动；另有有界管道读取线程。取消后终止并回收子进程，不等待界面线程。新建、打开、关闭或编辑不使用通用耗时任务锁。
- 解码最多 120 秒、4 小时源采样、8 GiB 流式 PCM 输出、32 声道；单文件峰值少于 2 MiB。仅会话内 LRU 缓存，最多 16 项／32 MiB；没有磁盘缓存。
- 同时请求最多 16 个可见来源，相同来源去重。超出范围、加载及失败分别显示「波形显示上限」「波形加载中」「波形不可用」。缺少 FFmpeg、损坏或过大文件只影响波形，不妨碍剪辑。
- 每次完成解码核对文件前后身份，并以请求代际过滤过期结果。可见来源周期性重查；路径替换、删除和工程切换不会将旧波形当成新素材。

## 与竞品的功能差距

这一轮补的是 Premiere Pro、DaVinci Resolve、剪映及 Final Cut Pro 常见的时间线音频可视定位能力中的基础部分。仍不宣称具备它们完整的轨道混音、响度测量与标准化、侧链／自动闪避、音频关键帧、专业音频效果链、处理后波形或采样级音频修整能力。原生 Windows／macOS 构建与实际设备回放不由本轮 Linux 离屏验证替代。
