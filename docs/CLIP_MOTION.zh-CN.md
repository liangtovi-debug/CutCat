# 画面位置、缩放与不透明度关键帧 · schema32

本轮增加手动画面动画：每个关键帧同时记录水平位置、垂直位置、等比缩放和整幅画面不透明度。四个值是绝对值，取代对应的静态值，不是叠加位移或乘数。旋转、镜像和「变换范围外透明」仍为静态设置；音频不受不透明度影响。无关键帧时保留原有静态处理路径。

## 时间与插值约定

- 帧号使用片段本地项目帧，不是素材帧，也不是时间线绝对帧。移动片段、滑移素材或改变速度不自动缩放关键帧时间。
- 每片段最多 128 个关键帧，帧号为 `-(2**53-1)` 至 `2**53-1` 的有符号整数，按帧号严格递增，不允许重复。
- 水平／垂直位移为项目像素，范围 -16384 至 16384；缩放范围 0.1 至 4；不透明度范围 0 至 1。
- 每个关键帧的「保持」或「线性」决定它到下一个关键帧之间的插值。保持在下一个关键帧到达前维持当前值；到达精确关键帧时使用该关键帧的四个值。
- 第一个关键帧之前和最后一个关键帧之后维持端点。只有一个关键帧时整个片段使用它的值。
- 线性插值对四个值分别采用 `a + (b-a) * ((frame-left)/(right-left))`。本地时间先用精确整数／分数运算，最终几何混合才转为浮点；端点范围钳制仅防止浮点舍入越界。
- 片段外关键帧包括负帧号都是有效的隐藏插值控制点，不自动删除、裁剪或补端点。这不代表片段外会输出画面。

## 编辑语义与撤销

- 分割：左片段保留所有原始关键帧；右片段的所有关键帧减去本地分割帧号，保留隐藏控制点和原插值。两侧的可见动画连续，不因素材速度变化而错位。
- 左边缘裁切／向左扩展：所有关键帧减去左边缘的项目帧变化量。向左扩展的变化量为负，所以关键帧本地帧号增加。
- 滚动剪辑点：仅右片段的关键帧减去剪辑点变化量；左片段的本地关键帧不变。预览和提交使用同一规则。
- 右边缘裁切／扩展、单片段和多片段移动、滑移、速度修改，以及数值式素材入出点／时长编辑：保持所有本地关键帧时间和值不变。
- 复制／粘贴调色不包含画面动画、静态几何或画面合成设置。
- 明确「转换为静态」时，在选定本地帧评估四个值，写回静态位置／缩放／不透明度后清空关键帧；旋转、镜像、透明开关和其他片段设置不变。整个操作只产生一个撤销步骤。
- 编辑溢出、无效数据或媒体／轨道不兼容会原子拒绝，不产生部分工程修改、撤销步骤或丢失重做历史。重复应用相同值和零变化编辑是真正空操作。

## 工程兼容与恢复

新工程保存为 schema32，每个片段显式保存 `motion_keyframes`，静态片段为空列表。schema1–31 的正常工程迁移为空列表，保留原静态画面效果；旧版本声明中夹带此字段会被拒绝，即使该值是空列表或 null。schema32 缺字段、多字段、错误类型、重复／乱序帧号、非有限数值或超过 128 项都会被拒绝。

保存、重新打开、恢复快照及撤销／重做均保留负帧和片段外关键帧。新字段追加到 Clip 构造参数末尾，不改变已有位置参数顺序。旧程序不能打开 schema32，不支持降级保存。请使用工程和素材副本测试。

## 当前验收边界

模型／数学测试覆盖独立有理数插值参考、精确端点、极值舍入、五种素材速度、隐藏关键帧连续性、裁切／分割／滚动预览与提交、原子失败、恢复、全部旧版本迁移及未知字段拒绝。这里描述的是源码行为和验证范围，不是当前 Windows/macOS 原生测试包已验收的证明。

## 操作方式和草稿保护

只选择一个视频片段，在「画面变换」区域打开「画面关键帧」。选择片段局部帧，修改四个数值，点击「添加／替换关键帧」。第一次添加直接采用当前静态数值，不暗中创建起止关键帧。时间轴支持整数帧拖动、键盘移动、上一／下一关键帧；目标帧冲突会拒绝，不覆盖另一关键帧。离开焦点或 Escape 取消正在进行的移动。

编辑器保留独立草稿，只有「应用动画」会提交一个撤销步骤；取消或不变的应用不修改工程。切换帧会丢弃尚未添加的数值，存在未添加数值时不能应用。隐藏关键帧以只读帧号列表显示；「将当前画面设为静态」会明确询问是否删除全部关键帧（包括隐藏关键帧），先保留当前帧计算后的四个值，仍需应用才写入工程。

存在画面关键帧时，主检查器的 X/Y、缩放和不透明度静态控件禁用，避免编辑不生效的参数；旋转、镜像、变换外部透明开关仍可修改。选择、工程、编辑会话、修订或播放头变化会使旧对话框失效，必须重新打开。这里不解码或伪装为实时画中画预览；应用后使用现有「构建预览」查看真实动画。暂停调色画面依旧在几何与合成之前，不是最终合成预览。

## 渲染、精度和缓存

生产渲染先完成精确的素材变速采样、调色／恢复及片段特效，再以局部输出帧计数 N 同时计算几何取样及覆盖 alpha，最后才叠加片段时间线起点。静态旋转／镜像仍参与逆变换。不透明度为零不会缩短画面或改变音频。字幕和贴纸仍在画面合成之后。

每次有动画的导出除静态检查外，还执行多帧 N 变化的几何／不透明度行为探测，独立验证输出样本；不支持则明确失败，不静默输出首帧静态画面或退化为 8 位。10 位画面保留 RGB16 到 YUV444 10 位 straight-alpha 合成，然后才降为交付的 4:2:2；8 位路径沿用静态画中画既定特效精度分支。真实黑色保持不透明；完全透明处精确保留下层样本。这里仍不是线性光、HDR、源 alpha 导入、抗锯齿边缘或竞品逐像素匹配。

表达式仅由严格验证的数字和内建运算生成，不接收用户表达式。128 个关键帧通过平衡区间树限制解析深度；长滤镜图通过既有文件选项传递，避免操作系统单参数长度限制。最终预览缓存包含动画数据及独立算法版本；几何之前的 RGB16 调色缓存可复用。

数学求值器的时间运算使用整数／有理数；FFmpeg 执行器使用双精度数值表达式，输出还包含采样、alpha 和颜色转换量化。应按实际位深像素容差验收，不宣称所有中间浮点数逐位一致。

## 与成熟编辑器的本轮对照

官方资料核对日期：2026-10-24。对照证明相关能力存在，不证明每项都是付费版本独占，也不证明本轮已超越这些产品。

- [Premiere 关键帧概览](https://helpx.adobe.com/premiere/desktop/add-video-effects/control-effects-and-transitions-using-keyframes/about-keyframes.html)：支持位置、缩放、不透明度等属性关键帧。CutCat 此轮补齐主视频 X/Y、等比缩放和不透明度的手动关键帧及真实预览／导出。
- [Premiere 插值控制](https://helpx.adobe.com/premiere/desktop/add-video-effects/control-effects-and-transitions-using-keyframes/control-effect-changes-using-keyframe-interpolation.html)：有更丰富的插值控制。CutCat 目前仅线性和保持，不包含贝塞尔曲线、缓入缓出、空间路径或速度图。
- [Final Cut Pro 视频效果关键帧](https://support.apple.com/en-tm/guide/final-cut-pro/ver8e3f20ea/mac)：可在视频动画编辑器中操作关键帧。CutCat 本轮提供独立的单片段草稿时间轴，不承诺相同的交互、独立属性轨道或实时查看器操控。

后续优先评估合成性能和直接查看器操作，再考虑有独立数学／交互验收的缓动曲线。旋转动画、自动跟踪、自由遮罩、任意轨数、混合模式和真正的视频转场仍未实现；单片段不透明度动画不能冒充带素材余量和双侧音频策略的交叉溶解转场。

### 本机有界性能记录

Linux、FFmpeg 7.1.5、单滤镜线程；每种尺寸／位深各一次，3 个变化帧、两个线性关键帧、静态旋转 17 度。1080p：8 位 21.67 秒，10 位 21.97 秒；4K：8 位 87.36 秒，10 位 86.25 秒。包括子进程启动、原始输入读取、滤镜和原始输出捕获；不含素材解码、调色、能力探测、音频、交付编码或界面。运行期间主机还有其他验证工作，不是独占机器基准；不使用平均值或吞吐承诺。

这些数据明确说明当前动态合成较慢，不是实时播放性能。性能优化是后续优先项，不用低位深中间结果或静态首帧回退换取速度。逐次参数与输出字节数见本轮验证回执。
