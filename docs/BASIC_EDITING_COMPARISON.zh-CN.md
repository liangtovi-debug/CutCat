# 剪辑猫基础剪辑补齐：差距与本轮实现

日期：2026-10-22。范围：当前源码，非新版 Windows/macOS 安装包。对照为公开官方功能说明，不是竞品逐项实机评测；不同版本、地区和付费档位不能据此视为一致。

## 结论

剪辑猫已有本地导入、四轨时间轴、单片段移动/数值修剪/分割、精确变速、素材滑移、相邻切点滚动剪辑、撤销重做、项目保存/重新链接、字幕、贴纸、基础音频与共享预览/导出。首要差距不是再增加 AI 按钮，而是常用时间轴操作与画面控制的完整度。本轮补齐两个边界清晰、可撤销和可保存的基础动作。

## 本轮已实现

### 1. 本轨波纹删除

入口：选择片段 → 片段 → 编辑 →「本轨波纹删除」。删除选中片段，将其后**同轨**片段左移所删片段的时间轴时长；保留原有间隙。一次撤销即可完整恢复。

- 普通「删除片段」与 Delete 键仍保留空隙，没有改变旧行为。
- 其他轨道（含其配乐/音效）、字幕、贴纸留在原时间位置；界面明确提醒，不伪装成全轨同步波纹。
- 同轨片段附带的源音频随片段一起移动，其他独立音频轨不移动；若选中音频轨上的片段，本轨后续音频同样会左移。
- 保留后续片段的源区间、分数变速尾部、淡入淡出、调色/效果/画面设置与来源记录。
- 遇到非法工程、同轨重叠或不存在的选择，操作失败且不留下部分更改。
- 当前没有锁轨数据模型，不宣称支持锁轨、同步锁或跨轨链接编辑。

### 2. 静态主视频画面变换

入口：选择视频片段 → 片段 → 编辑 →「画面变换」。设置后点「应用画面变换」，重新构建预览；重置、撤销与重做均支持。

- 水平/垂直位置：−16384 至 16384 项目像素；缩放：0.10–4.00；旋转：−180° 至 180°；水平/垂直镜像。
- 先将素材按旧规则等比适配并补黑边到项目画布，再以画布像素中心进行镜像、缩放、旋转，最后位移；正旋转为顺时针。
- 非视频轨禁用此控制；默认参数完全旁路，不改变旧版工程原来的渲染链。
- 在同一预览/导出渲染图内工作，静态设置随片段分割、项目保存与重新打开保留。新工程格式为 schema16，旧工程迁移为恒等变换；旧阅读器应拒绝新格式，而非忽略设置。
- **这是不透明画布，不是透明画中画合成**。变换后的空白填黑，上层视频的黑底仍会遮住下层视频。没有新增裁切工具、透明度、关键帧动画或直接在预览器拖拽变换。
- 该原型仍需离线构建预览。任意角度/缩放/位移使用固定画布的 CPU 逆向采样，避免大倍数缩放分配巨型临时帧；不宣称实时交互或专业软件性能相当。性能与最终验收见本文件末尾。

### 性能实测（合成片段，仅本执行环境）

相同 6 帧 1920×1080、2 个 FFmpeg 滤镜线程、包含进程启动开销：不变换约 0.067 秒；原生镜像快速路径约 0.126 秒（总耗时 1.88 倍，约 0.021 秒/帧）；180° 快速路径约 0.132 秒；任意组合变换约 4.114 秒（约 61 倍，约 0.686 秒/帧）。正方形 1080×1080 的 90° 原生路径约 0.103 秒。此为微基准，不是完整工程实时性能或跨设备承诺。普通镜像/半圈旋转已优化；任意变换性能仍有明显差距。

### 最终冻结源码验收

- 完整回归：**3832 通过、2 跳过、0 失败**，1290.03 秒。2 项跳过分别为显式本地 CJK 字体测试夹具未配置、需要原生 Windows 盘符语义；不是被当成通过。
- 变换：35 项严格参数/真实像素测试、12 项完整媒体集成测试；本轨波纹：31 项模型与 6 项完整媒体测试。
