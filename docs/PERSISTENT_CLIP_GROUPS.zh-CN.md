# 持久片段编组（本地源码轮）

在时间线选择至少两个尚未编组的视频或音频片段，在“编辑”菜单选择“编组片段”。工程格式 36 保存独立组 ID 和成员片段 ID。点击成员选择整组，Shift 点击以整组为单位切换；组标记可区分临时多选与已保存的关系。取消编组只解除关系，不改变画面或声音。新快捷键预设使用 Ctrl/Cmd+G 编组、Ctrl/Cmd+Shift+G 取消编组；已有自定义快捷键配置不会被覆盖，新命令保持未绑定，可在设置中指定。

整组可在原轨道上水平移动，所有成员使用同一个整帧位移。时间线零点、碰撞和现有转场规则仍然生效，不能分别截断或自动改变成员位置。非波纹删除整组时一并删除组记录，但不删除素材或磁盘文件。编组、取消编组、移动和删除都使用单次原子撤销，保存、重开与恢复保留关系。

单个成员的拆分、修边、滑移、变速、滚动剪辑、替换来源或跨轨移动要求先取消编组。组边缘点击不会启动修边。现有单轨波纹删除若删除或推动任一组成员，会拒绝执行。转场端点的删除仍要求先显式移除转场，不自动级联。

> 后续 schema39 候选现已新增完整组的窗口私有复制／原轨粘贴，详见[复制粘贴边界](CLIP_COPY_PASTE.md)。下列“不包括组复制”描述保留原编组轮历史范围，不代表后续候选缺少该入口。

## 边界与后续对标

这不是轨道锁定、同步锁、磁性时间线或音画链接。当前不包括嵌套组、字幕／贴纸组、组复制或整组外缘修剪；追加素材不会自动加入现有组。多选检查器仍不提供批量调色或音量编辑，不把组关系变成信号处理状态。

Adobe Premiere 官方说明将组移动、组删除与受限制的组内修剪分开，并支持比本轮更宽的外缘修剪／复制工作流：[Group clips](https://helpx.adobe.com/sg/premiere/desktop/edit-projects/change-clip-sequence/group-clips.html)。[Sync Lock](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/sync-lock-to-prevent-changes.html) 是插入及波纹操作时的轨道参与行为，不等于持久编组。DaVinci Resolve 的[剪辑功能](https://www.blackmagicdesign.com/se/products/davinciresolve/edit)也将轨道目标、锁定等工具分开描述。后续循环仍需独立定义和验证这些缺口，不能宣称本轮已覆盖付费版本全部能力。

## 验证与交付范围

验收覆盖 schema 1–35 的历史迁移、36 的严格字段校验、无副作用失败、撤销重做、恢复、鼠标及焦点行为、真实视频与 PCM 信号不变性。最终测试计数、精确源码哈希、界面截图及新鲜解压结果记录在本轮独立验收报告中；本说明不把尚未执行的验证当作通过。

仅本地 Linux 源码与离屏 Qt 验证。没有新 Windows/macOS 安装包、原生平台播放性能、GPU 加速或远端 main 更新声明。用户素材不上传，不变更依赖、账户或付费服务。
