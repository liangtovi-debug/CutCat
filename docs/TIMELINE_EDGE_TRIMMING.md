# 时间线直接修边 / Direct timeline edge trimming

本轮在现有四条视频／音频轨道上加入单片段、非波纹的左右边缘拖动，与上一轮的源音频波形配合定位。拖动片段内部仍是移动，数值修剪、滑移和滚动剪辑入口继续保留。

## 使用方式与安全边界

- 拖动片段左边或右边，以工程整帧为步长调整该边。另一边固定，其他片段、轨道、字幕和贴纸不移动。短片段的边缘命中区重叠时选择最近的边；正中相等时选择左边。
- 拖动只显示候选轮廓和帧数，不改写工程，不渲染预览，也不为每次鼠标移动重新解码波形。松开鼠标后提交一次编辑，可一次撤销／重做。
- 缩短至少保留一帧；延长只能使用可用源素材范围，并拒绝与同轨邻片段冲突。不会自动挤开或覆盖邻片段，也不会静默缩短已有淡入淡出。
- 左边移动时同步调整片段起点和源入点，保留源出点；右边移动只调整源出点。使用精确有理数时间映射，保留变速片段不足一整帧的源尾段，避免重复修剪逐渐吃掉或增加尾部。
- 左边修剪会平移颜色窗口动画的局部时间，隐藏于可见范围之外的关键帧仍保留；右边修剪不重排关键帧。
- Escape、失去焦点、关闭、工程或选区改变、编辑版本变化、目标删除均取消未完成手势。波形后台完成不应使手势失效。无改动或非法候选不会创建历史记录。

## 验证范围

模型、真实 Qt 手势和合成媒体测试覆盖左右缩短／延长、源范围／相邻冲突、不同缩放比例、撤销和取消。合成画面具有可识别帧号；实际渲染像素及确定性 PCM／脉冲用于核对源选择、边界和静音尾段。帧率包含 24000/1001 与 30000/1001，变速包含 1/4、1、1.5、4 倍。完整验收数量、精确节点、源码身份及源包解压验证以本轮独立证据为准。

工程 schema 30 和渲染管线不变。本地 Linux 离屏验证不能替代 Windows／macOS 原生构建、真实鼠标／触控板操作及设备音视频回放。本轮不宣称交付双平台安装包。

## 与竞品的定位

补的是常见的单片段基础修边操作，不是波纹、双边滚动、磁性时间线、联动多轨或多选修剪。现有数值滚动剪辑与本轮直接修边是独立操作；拖动共享边界不会自动联动另一片段。源波形仍是增益／淡化前的近似源时间包络，不是处理后波形或采样级音频精修。
