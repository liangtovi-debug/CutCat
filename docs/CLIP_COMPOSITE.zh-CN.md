# 静态画中画与片段不透明度 · schema31

本文记录 schema31 引入的静态功能边界。当前累计源码保存为 schema32，并新增 [画面位置、缩放与不透明度关键帧](CLIP_MOTION.zh-CN.md)；以下 schema31 描述保留为功能引入时的兼容记录。

## 本轮解决什么

上层视频缩小或移位后，可以显式选择让变换后画布外区域露出下层视频。新增片段不透明度 0–100%，只改变画面，不静音、不缩短片段、不改变源音频及淡入淡出。两个主视频轨仍为原有上、下层关系。

旧工程和新片段默认仍为“不透明画布、100%不透明度”。默认值完全旁路新增合成滤镜及能力探测，沿用原有黑色画布变换路径；不会把旧工程的黑底自动变透明。新保存为 schema31，旧读者应拒绝打开；保留工程及媒体备份。

## 使用与边界

只选中一个主视频片段，在现有“画面变换”区域调整位置、缩放、旋转或镜像，再启用透明外部画布或调整不透明度并应用。多选、字幕、贴纸、音频目标不接受这些单片段修改。建立完整预览或导出查看结果。

这里的透明区域仅是“变换后，原先已适配到工程尺寸的完整画布之外”。适配产生的画布内部黑边仍是画面；真实黑色内容仍然不透明。不按亮度抠黑，不自动去黑边，不读取素材原有 alpha，不新增裁切或抠像。

暂停时的当前帧调色视图仍是选中片段在特效、几何、合成之前的画面，不是完整画中画预览。最终预览缓存包含合成参数及算法版本；已调色的片段缓存可以复用。

## 像素约定

- 已适配、调色和处理特效的源画布进入几何采样。镜像先按源轴执行，再按画布像素中心缩放、顺时针旋转，最后按工程像素平移。
- 覆盖率取同一逆变换下的像素中心是否落在原画布范围内，为硬边界；没有新增边缘抗锯齿/羽化保证。alpha 为几何覆盖率乘静态不透明度，不从 RGB 亮度生成。
- 使用 straight（非预乘）alpha。采样颜色不再乘 alpha，避免混合时二次衰减。最后行列的保护像素避免双线性采样器错误钳位，不让保护黑色渗入有效源边界。
- 全色度 Rec.709 编码值空间 source-over 混合后，再降采样为 H.264 的 4:2:0 或 ProRes 的 10-bit 4:2:2。不是线性光、HDR、ICC、广色域合成或竞品算法逐像素匹配。
- H.264 新合成路径中的活动模糊/暗角先在显式 RGB8 中执行，再扩展为 RGB16 进入合成；这与旧默认路径的格式协商可能不同，不承诺两种路径逐像素一致。无活动特效时可直接保留调色后的 RGB16 到混合转换。带活动模糊的新 H.264 合成还需通过独立的标量 RGB8 行为探测，并关闭优化 CPU 分派，以避开窄画幅模糊损坏；因此会有额外性能成本，默认旧工程不受此新增探测/分派规则影响。
- 高位深主视频保持 RGB16 到带 alpha 的 10-bit YUV444，不经过 RGBA8。显式 zscale 矩阵/范围转换，不静默更换低精度路径。
- 完全透明区域需精确保留输入下层 YUV 样本；有覆盖的色度采样格则包含该格内覆盖与未覆盖像素的平均结果，这是最后色度降采样，不代表自动抠像。
- 新路径每次构建导出时先执行独立的有界 FFmpeg 行为探测。缺失或不兼容的滤镜应明确失败，不静默降为 8-bit。

## 与付费编辑器工作流对比

核对官方文档日期：2026-10-24。文档证实相关能力，不证明这些功能均为收费版独占。

- [Premiere Motion](https://helpx.adobe.com/premiere/desktop/add-video-effects/commonly-used-effects/apply-motion-effect.html)：位置、缩放和旋转及查看器控制。CutCat 此轮复用已有静态数值变换，不新增查看器拖动控制。
- [Premiere 合成](https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-composites/compositing-overview.html)：上轨与下轨按 alpha 合成，并支持导入 alpha。CutCat 此轮只补两轨普通静态画中画和恒定不透明度，不支持导入视频 alpha。
- [Premiere 混合模式](https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-composites/combine-multiple-videos-or-stil-images-using-blend-modes.html)：还提供不同混合模式；CutCat 仍只有普通 source-over。
- [Final Cut Pro 不透明度](https://support.apple.com/en-ie/guide/final-cut-pro/ver52cf3376/mac)：不透明度、淡变手柄及关键帧；[alpha 通道](https://support.apple.com/guide/final-cut-pro/use-alpha-channels-ver52cf382e/mac)。本轮不包含主视频变换/不透明度关键帧、自由遮罩、视频转场、任意轨数或互动合成。

下一轮应在当前静态合成稳定后再评估主视频关键帧的片段局部时间与修剪/分割语义，或真实转场的素材余量、重叠及音频策略。不能把本轮静态透明度当成已完成交叉溶解转场。

### 本机有界合成性能测量

Linux、FFmpeg 7.1.5、单滤镜线程；每种尺寸/位深仅一次、一个合成帧，缩放0.5、旋转17度、不透明度0.5。1080p：8-bit 1.47秒，10-bit 1.55秒；4K：8-bit 5.94秒，10-bit 6.01秒。计时包括子进程启动、原始输入读取、滤镜及原始输出捕获；不含素材解码、调色、缓存、音频、能力探测、交付编码或界面。这不是实时播放或完整工程导出基准，不代表其他机器性能。详细参数、字节数及复现脚本保存在本轮验证证据中。
