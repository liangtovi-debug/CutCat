# 剪辑猫受控编辑：验证记录

日期：2026-10-21。平台：Linux / Python 3.12 / PySide6 6.8.3。
本轮源码新增实验性的离线编辑预览，不是完整自动剪辑 agent。

## 实现范围

- 只允许已有字幕文本替换、指定含音频片段的绝对增益修改。
- 模型/适配器只能返回候选建议，不获得可变编辑器、shell、任意路径或写入工具。
- 选中目标范围、严格 JSON、不可变快照、核心会话及单调版本、前后状态摘要、准确差异预览、一次性确认、原子提交和整批一步撤销。
- 项目/选择/模型/输入变更、取消、迟到结果、重复应用及确认弹窗期间变化均拒绝旧建议。
- 原本地字幕校对保留并接入安全层；人工修订明确区分，必须重新预览。
- 可选 openai-agents==0.24.0：实际 Agent/Runner + 本地静态假模型；默认程序无需此依赖，不联网调用真实模型，不保存密钥，不自动转云，禁用远程追踪导出。

- 核心事务与严格边界：64 项通过（含编辑器深复制保留历史、隔离会话与锁）。

- 最终 Qt 界面、原 AI 界面、全套布局与本地化专项：115 项通过。
- API 配置、主窗口接入与本地化专项：111 项通过。
- 最终独立安全/隐私复核：291 项通过；包含 34 项独立编写的场景，另有 1,000 次畸形候选探测，均受控拒绝。上述专项有重复覆盖，不与全量测试相加。
- 不安装可选 SDK 的默认环境：114 项通过、17 项 SDK 专项明确跳过；原离线路径不依赖该 SDK。
- 真实媒体：4 项通过，覆盖30与29.97 fps、±6 dB。

- 字幕按原始起止帧显示；除允许的文本/增益外，ID、时间、样式、语言、淡入淡出、静音及其他对象保持不变。
- 撤销/重做后重新渲染的画面和PCM，与对应原结果精确一致。另测预览/导出、缓存变化、保存重开。
- 真实中英文Qt界面及确认弹窗截图9张（含中英文320像素窄面板），人工查看中文可读性、差异内容和控件布局。截图测试实际点击确认/拒绝，验证输入修订需重预览、整批应用只递增一次、一步撤销恢复。
